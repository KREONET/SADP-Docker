# 4. 번역(i18n)

## 한눈에

- 화면의 모든 문구는 **영어 원문을 키로** 씁니다: `{{ __('Save') }}`
- 한국어는 `lang/ko.json` 에 `"Save": "저장"` 처럼 추가합니다.
- 어떤 언어로 보일지는 ① 사용자 개인 설정 → ② 인스턴스 기본 언어(설정 → 일반) → ③ 브라우저 언어 순서입니다.
  (코드: `app/Support/InterfaceLocale.php`, `app/Http/Middleware/SetInterfaceLocale.php`)
- 언어 목록은 `config/app.php` 의 `available_locales` 입니다.

## 새 문구를 추가하는 방법

1. Blade 또는 PHP 에서 `__('Your text')` 로 감싼다.
   - 변수가 들어가면 `__('Hello :name', ['name' => $user->name])`
   - **문자열을 이어 붙이지 마세요.** `__('Hello ').$name` 은 번역할 수 없습니다.
   - 키는 반드시 따옴표 안의 **고정된 문자열** 이어야 합니다. 변수를 키로 쓰면 번역 누락 검사가 찾지 못합니다.
2. `lang/ko.json` 에 같은 문구를 키로 해서 한국어를 추가한다. 변수(`:name`)는 **그대로 유지**.
3. 테스트 실행:
   ```bash
   ./scripts/dev exec php artisan test --compact tests/Feature/KoreanTranslationsTest.php
   ```
   - "every interface string has a korean translation" — 번역을 빠뜨리면 어떤 파일의 어떤 키인지 알려 줍니다.
   - "keep the placeholders" — `:name` 같은 자리 표시자가 번역에서 사라지거나 바뀌면 실패합니다.

## 자주 하는 실수

| 실수 | 증상 | 해결 |
|---|---|---|
| 영어 문구를 고쳤는데 한국어가 그대로 | 키가 바뀌어서 번역을 못 찾고 영어가 보임 | `ko.json` 의 키도 같이 바꾼다 |
| `ko.json` 에 같은 키를 두 번 씀 | 마지막 값만 쓰임 | 하나만 남긴다 |
| JSON 문법 오류 (끝 쉼표 등) | 모든 문구가 영어로 보임 | `python3 -m json.tool lang/ko.json` 으로 확인 |
| 코드 예제 안의 `__('…')` | 번역 검사가 예제도 센다 | 예제의 문구도 `ko.json` 에 넣는다 (`/dev/ui` 의 "Check the logs." 처럼) |
| `<x-status-badge status="Shipping">` 처럼 글자를 그대로 씀 | 번역되지 않음 | `:status="__('Shipping')"` |

## 새 언어를 추가하려면

1. `lang/ja.json` 처럼 키가 같은 파일을 만든다 (`lang/en.json` 이나 `ko.json` 을 복사해서 시작).
2. `config/app.php` 의 `available_locales` 에 `'ja' => '日本語'` 를 추가한다.
3. 사용자 설정과 인스턴스 기본 언어 선택에 자동으로 나타납니다.
4. `KoreanTranslationsTest` 를 참고해서 같은 방식의 번역 누락 테스트를 추가하세요.
