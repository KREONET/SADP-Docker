# 1. 시작하기

## 준비물

Docker 만 있으면 됩니다. PHP, Node 를 컴퓨터에 따로 깔 필요가 없습니다. 모든 명령은 컨테이너 안에서 실행합니다.

## 데모 환경으로 한 번에 실행

```bash
COOLIFY_DEV_SERVER_BACKEND=testing-host ./scripts/dev demo
```

- 앱과 DB, Redis, Vite(CSS/JS 개발 서버), Loki, Grafana 를 띄우고 **모든 화면이 채워지도록 데모 데이터**를 넣습니다.
  (데이터를 만드는 코드: `app/Actions/Development/SeedDevelopmentDemo.php`)
- 주소와 포트는 `./scripts/dev urls` 로 확인합니다. 기본 브랜치(main)는 `http://localhost:8000` 입니다.
- 로그인: `test@example.com` / `password` (플랫폼 관리자 계정)
- 원격 서버에서 돌린다면 SSH 터널로 `localhost:8000` 을 열어서 보세요. (`ssh -L 8000:localhost:8000 서버`)

| 명령 | 하는 일 |
|---|---|
| `./scripts/dev start` | 일반 개발 환경 시작 |
| `./scripts/dev demo` | 데모 데이터와 Loki/Grafana 포함 시작 |
| `./scripts/dev stop` | 멈춤 (데이터는 남음) |
| `./scripts/dev exec <명령>` | 앱 컨테이너 안에서 명령 실행 (예: `./scripts/dev exec php artisan migrate`) |
| `./scripts/dev urls` | 주소 목록 |
| `./scripts/dev destroy <이름>` | 컨테이너와 데이터까지 삭제 |

## 화면을 고치면 바로 보이나요?

- **PHP / Blade 수정**: 새로고침하면 바로 반영됩니다.
- **CSS / JS 수정**: Vite 가 자동으로 반영합니다.
- **완전히 새로 만든 Blade 파일에서 처음 쓴 Tailwind 클래스**는 반영되지 않을 수 있습니다.
  (Tailwind 가 컴파일된 뷰를 읽는데 Vite 설정이 `storage/**` 를 감시에서 빼 두었기 때문입니다.)
  이때는 Vite 컨테이너를 재시작하세요: `docker restart <브랜치>-vite 컨테이너` — 이름은 `docker ps` 로 확인합니다
  (main 브랜치는 `coolify-dev-main-vite-1`). 또는 `npm run build` 를 실행합니다.

## 테스트 실행

```bash
./scripts/dev exec php artisan test --compact                       # 전체 (오래 걸립니다)
./scripts/dev exec php artisan test --compact tests/Feature/Dev     # 폴더 하나
./scripts/dev exec php artisan test --compact --filter=이름          # 이름으로 하나
./scripts/dev exec vendor/bin/pint --dirty --format agent           # 바꾼 PHP 파일 코드 스타일 정리
```

- 테스트는 메모리 DB 를 쓰므로 개발 DB 는 건드리지 않습니다.
- 처음에는 **내가 바꾼 기능의 테스트 파일만** 돌리세요. 전체 테스트는 PR 직전에 한 번 돌리면 됩니다.
- `Pint` 는 반드시 `--dirty` 로 바꾼 파일에만 쓰세요. 아니면 상관없는 파일까지 서식이 바뀝니다.

## 처음 둘러볼 순서 (추천)

1. `./scripts/dev demo` 로 띄우고 로그인한다.
2. `/dev/ui` 를 열어 공통 부품을 본다. 오른쪽 위 프로필 → 화면 설정에서 밀도·글자 크기를 바꿔 보고 `/dev/ui` 가 어떻게 변하는지 본다.
3. `/platform/logs` (로그 화면)의 Blade 파일 `resources/views/livewire/platform/logs.blade.php` 와 PHP 클래스 `app/Livewire/Platform/Logs.php` 를 나란히 연다.
   화면의 버튼이 클래스의 어느 메서드를 부르는지(`wire:click`) 찾아 본다.
4. [화면 고치기](02-화면-고치기.md) 의 레시피를 따라 작은 변경(문구, 버튼 하나)을 해 본다.
