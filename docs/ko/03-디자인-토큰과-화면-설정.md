# 3. 디자인 토큰과 화면 설정

## 사용자가 바꾸는 것

프로필 메뉴 → **화면 설정(Appearance) → 화면 크기(Display size)**

| 설정 | 선택지 | 저장 위치 |
|---|---|---|
| 밀도(컨트롤 크기) | 자동 / 촘촘하게 / 편안하게(기본) / 터치 | 브라우저 `localStorage.uiDensity` |
| 글자 크기 | 작게 / 보통 / 크게 / 아주 크게 | 브라우저 `localStorage.uiTextSize` |

- "자동"은 터치 화면(`pointer: coarse`)이면 터치, 아니면 편안하게로 정합니다.
- 서버에 저장하지 않으므로 기기마다 따로 설정됩니다. 로그인 전 화면에도 적용됩니다.

## 동작 원리 (3단계)

1. `resources/views/layouts/base.blade.php` 의 `<head>` 스크립트가 페이지가 그려지기 **전에** 저장값을 읽어
   `<html data-density="touch" data-text-size="large">` 처럼 속성을 붙입니다. (깜빡임 방지)
2. `resources/css/design-tokens.css` 가 그 속성에 따라 `--ui-h-md` 같은 CSS 변수 값을 바꿉니다.
3. 버튼·입력·메뉴·표의 CSS 가 변수를 읽어 크기를 정합니다. (`resources/css/utilities.css`, `app.css`)

## 크기를 바꾸고 싶다면

| 하고 싶은 일 | 고칠 곳 |
|---|---|
| 모든 버튼/입력 높이를 키우기 | `design-tokens.css` 의 `--ui-h-md` (밀도별로 따로 있음) |
| "터치" 모드를 더 크게 | `[data-density="touch"]` 블록의 값 |
| 새 밀도(예: 아주 촘촘하게) 추가 | ① `design-tokens.css` 에 `[data-density="새이름"]` 블록 추가 ② `base.blade.php` 의 `window.UI_DENSITIES` 에 이름 추가 ③ `components/theme-controls.blade.php` 에 카드 추가 ④ `lang/ko.json` 번역 |
| 글자 배율 바꾸기 | `html[data-text-size=…]` 블록 (`font-size` 와 `--ui-text-scale` 을 **같은 비율**로) |

변경 후 `/dev/ui` 에서 모든 밀도로 확인하세요. 맨 위의 "디자인 토큰" 표가 현재 값을 실시간으로 보여 줍니다.

## 새 컴포넌트를 만들 때 규칙

- 높이: `h-8`, `h-9`, `size-8` 같은 **기존 클래스를 그대로** 쓰세요. 보정 층이 자동으로 토큰으로 바꿔 줍니다.
  CSS 를 직접 쓸 땐 `height: var(--ui-h-md)`.
- 정사각형 버튼은 `h-8 w-8` 대신 **`size-8`**. (`h-8` 만 커지고 `w-8` 은 그대로라 찌그러집니다)
- 글자는 `text-sm`, `text-xs` 처럼 rem 기반 클래스를 쓰면 글자 크기 설정을 자동으로 따릅니다.
  `text-[12px]` 같은 px 값은 보정 목록(`design-tokens.css` 의 "보정 층")에 있는 것만 따릅니다. 새 px 값은 거기에 한 줄 추가하세요.
- `h-8!` / `text-[12px]!` 처럼 `!` 를 붙인 클래스는 `@layer base` 안에 보정이 있어야 합니다. (아래 "왜 `@layer base` 인가요?")
- `sm:h-8` 처럼 앞에 접두사가 붙은 클래스(반응형)는 보정되지 않습니다. 필요하면 `sm:h-[var(--ui-h-md)]` 를 쓰세요.

### 왜 `@layer base` 인가요?
CSS 에서 `!important` 는 일반 규칙과 우선순위가 반대입니다. 레이어 안의 `!important` 는 레이어 밖의 `!important` 를 이깁니다.
Tailwind 의 `h-8!` 는 `utilities` 레이어 안이므로, 덮어쓰려면 더 앞선 `base` 레이어에 `!important` 로 써야 합니다.
(레이어 밖에 쓰면 아무리 `!important` 를 붙여도 적용되지 않습니다.)

## 색

- 면(배경) 색: `resources/css/app.css` 의 `--coollabs-canvas / elevated / base / recessed / fill / line`
- 밝은/어두운 모드가 따로 정의되어 있습니다. 색을 바꾸면 **두 모드 모두** 확인하세요.
- 자세한 디자인 원칙은 루트의 `DESIGN.md` (영어, 세부 규칙의 기준 문서).
