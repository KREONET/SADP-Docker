## 30초 요약

- 이 프로젝트는 **Laravel 12 + Livewire 3 + Tailwind 4** 입니다. 별도의 프런트엔드 프레임워크(React 등)는 없습니다.
- 화면 하나는 보통 **PHP 클래스 하나**(`app/Livewire/…`)와 **Blade 파일 하나**(`resources/views/livewire/…`)입니다.
  버튼을 누르면 PHP 클래스의 메서드가 실행되고, 값이 바뀌면 화면이 자동으로 다시 그려집니다.
- 공통 부품(버튼, 입력칸, 표 등)은 `resources/views/components/` 에 있고 `<x-forms.button>` 처럼 부릅니다.
  **개발 모드에서 `/dev/ui` 를 열면 모든 부품의 실제 모습과 복사해 쓸 코드가 있습니다.**
- 크기·글자 크기는 `resources/css/design-tokens.css` 한 파일에서 정합니다. 사용자는 프로필 → 화면 설정에서 직접 바꿀 수 있습니다.
- 사용자에게 보이는 모든 문구는 `__('English text')` 로 감싸고, `lang/ko.json` 에 한국어를 추가합니다.
- 테스트는 `tests/Feature/` 에 있고(Pest), 문구 번역 누락도 테스트가 잡아 줍니다.

## 꼭 지킬 규칙 (어기면 테스트가 실패합니다)

1. 화면 문구는 `__()` 로 감싸고 `lang/ko.json` 에 번역을 넣는다. (`KoreanTranslationsTest`)
2. `confirm()`, `wire:confirm` 같은 브라우저 기본 대화상자를 쓰지 않는다. `<x-modal-confirmation>` 을 쓴다. (`NoNativeBrowserDialogsTest`)
3. 사용자별·팀별로 달라지는 읽기/쓰기에는 항상 서버에서 권한 확인(`$this->authorize(...)`)을 한다. 숨긴 버튼(`@can`)은 보안이 아니다.
4. 버튼·입력의 높이는 `h-8` 처럼 기존 클래스를 쓴다. 새 고정 px 높이를 만들지 않는다. (화면 설정이 깨집니다)
5. 변경에는 테스트를 같이 추가한다.
