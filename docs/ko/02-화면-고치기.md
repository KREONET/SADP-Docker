# 2. 화면 고치기

## 화면은 이렇게 생겼습니다

```
주소(routes/web.php)
   └─ Livewire 클래스 (app/Livewire/…)      ← 데이터, 버튼을 눌렀을 때의 동작(PHP)
        └─ Blade 파일 (resources/views/livewire/…)   ← 보이는 모양(HTML + <x-부품>)
             └─ 공통 부품 (resources/views/components/…)   ← 버튼, 입력칸, 표 …
```

예: `/platform/logs`

| 무엇 | 어디 |
|---|---|
| 주소 | `routes/web.php` 의 `Route::get('/logs', PlatformLogs::class)` |
| 동작 | `app/Livewire/Platform/Logs.php` |
| 모양 | `resources/views/livewire/platform/logs.blade.php` |

### Livewire 를 3줄로 이해하기

- 클래스의 `public` 변수(`public string $name`)는 화면의 입력칸과 연결할 수 있습니다: `<x-forms.input id="name" />`
- `wire:click="save"` 는 버튼을 누르면 클래스의 `save()` 메서드를 실행하라는 뜻입니다.
- 메서드가 끝나면 화면의 바뀐 부분만 자동으로 다시 그려집니다. JavaScript 를 쓸 일이 거의 없습니다.

## 레시피

### A. 문구만 바꾸기
1. Blade 에서 `{{ __('Save') }}` 를 찾는다.
2. 영어 원문을 바꾸면 번역 키가 바뀌므로, **한국어만 바꾸려면 `lang/ko.json` 의 값만** 고친다. 영어 문구를 바꿔야 한다면 `ko.json` 의 키도 같이 바꾼다.
3. [번역 문서](04-번역.md) 참고.

### B. 버튼 추가하기
```blade
<x-forms.button type="button" wire:click="refreshNow">{{ __('Refresh') }}</x-forms.button>
```
```php
public function refreshNow(): void
{
    $this->authorize('update', $this->settings);   // 권한 확인 — 잊지 마세요
    // … 할 일 …
    $this->dispatch('success', __('Done.'));         // 초록색 알림(토스트)
}
```
- 위험한 동작(삭제 등)은 `<x-modal-confirmation>` 으로 한 번 더 묻습니다. 예제: `/dev/ui` 의 "확인 창".
- 알림 종류: `success`, `error`, `warning`, `info` — `$this->dispatch('종류', '제목', '설명')`

### C. 입력칸이 있는 설정 폼 추가하기
```php
public string $lokiUrl = '';

public function save(): void
{
    $this->authorize('update', instanceSettings());
    $this->validate(['lokiUrl' => ['nullable', 'url']]);   // 검증 실패 시 칸 아래에 오류가 자동으로 표시됩니다
    // 저장…
}
```
```blade
<form wire:submit="save">
    <x-application.settings-section :title="__('Loki')" :description="__('Where logs are sent.')">
        <x-forms.input id="lokiUrl" :label="__('Loki URL')" />
        <x-forms.button type="submit" isHighlighted>{{ __('Save') }}</x-forms.button>
    </x-application.settings-section>
</form>
```
실제 예: `resources/views/livewire/platform/sources.blade.php`.

### D. 새 화면(페이지) 추가하기
1. 클래스 만들기: `./scripts/dev exec php artisan make:livewire Platform/MyPage --no-interaction`
   (`app/Livewire/Platform/MyPage.php` 와 Blade 가 생깁니다)
2. 주소 등록: `routes/web.php` 의 같은 그룹 안에 한 줄 추가. 플랫폼 관리자 전용이면 `platform` 그룹 안에 넣습니다.
   ```php
   Route::get('/my-page', PlatformMyPage::class)->name('platform.my-page');
   ```
3. 메뉴에 넣기: 같은 영역의 사이드바 Blade(예: `resources/views/components/platform/` 아래)에 링크를 추가한다.
4. 권한: 라우트 그룹의 `can:` 미들웨어 + 클래스 메서드의 `$this->authorize()`. **둘 다** 필요합니다.
5. 문구는 `__()` 로, 한국어는 `lang/ko.json` 에.
6. 테스트: 열리는지, 권한 없는 사용자는 막히는지, 다른 팀의 데이터는 안 보이는지. (`tests/Feature/Dev/UiCatalogTest.php` 를 참고)

### E. 표에 열 추가하기
`<x-data-table>` 형태를 따릅니다. `/dev/ui` 의 "표" 예제를 복사해서 시작하세요. 목록의 각 줄에는 **`wire:key` 에 DB id 처럼 바뀌지 않는 값**을 넣어야 합니다. (`$loop->index` 사용 금지 — 삭제할 때 화면이 깨집니다)

### F. 색과 크기 바꾸기
- 크기: [디자인 토큰](03-디자인-토큰과-화면-설정.md)
- 색: `resources/css/app.css` 의 `--coollabs-*` 변수. 밝은/어두운 모드가 따로 있으니 둘 다 확인하세요.

## 공통 부품 목록

`/dev/ui` 가 최신 목록입니다. 자주 쓰는 것:

| 부품 | 용도 |
|---|---|
| `<x-forms.button>` | 버튼 (`isHighlighted` 강조, `isError` 위험) |
| `<x-forms.input>` / `textarea` / `checkbox` | 입력, 여러 줄, 체크박스 |
| `<x-forms.listbox>` | 선택 목록 (브라우저 기본 select 대신) |
| `<x-application.settings-section>` | 설정 묶음 카드 |
| `<x-callout>` | 안내/경고 상자 |
| `<x-status-badge>` | 상태 표시 배지 |
| `<x-empty>` | "데이터 없음" 화면 |
| `<x-modal-confirmation>` | 확인 창 |
| `<x-reicon>` | 아이콘 |

## 권한 규칙 한눈에

- **플랫폼 관리자**: 인스턴스 전체를 관리하는 사람(루트 팀(id=0)의 관리자 또는 소유자). `Gate: accessPlatformAdmin`. 인스턴스 설정, 소스(Git) 관리, 로그 화면이 여기 속합니다.
- **팀 역할**: member < admin < owner (`app/Enums/Role.php`).
- 모든 조회는 현재 팀으로 한정하세요. 주소나 id 는 믿지 마세요: `Application::ownedByCurrentTeam()->where('uuid', $uuid)->firstOrFail()` 처럼 팀 범위를 먼저 건 뒤 찾습니다.
