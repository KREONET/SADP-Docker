# 5. 기능별 지도

"어떤 기능의 코드가 어디 있나"를 찾는 표입니다. 각 PHP 파일 위쪽에 한국어 설명(주석)이 있으니 먼저 읽어 보세요.

## 플랫폼 관리자 영역 (`/platform/*`)

플랫폼 관리자(루트 팀의 관리자·소유자)만 접근합니다. 라우트 그룹 `can:accessPlatformAdmin` (`routes/web.php`).

| 메뉴 | 주소 | PHP | Blade |
|---|---|---|---|
| 대시보드 | `/platform` | `app/Livewire/Platform/Dashboard.php` | `resources/views/livewire/platform/dashboard.blade.php` |
| 소스 | `/platform/sources` | `Platform/Sources.php`, `Platform/GitSources.php` | `livewire/platform/sources.blade.php`, `git-sources.blade.php` |
| 로그 | `/platform/logs` | `Platform/Logs.php` | `livewire/platform/logs.blade.php` |
| 보안 / 그룹 / 애플리케이션 | … | `Platform/Security.php` 등 | 같은 이름의 Blade |

인스턴스 설정(`/settings/…`)도 플랫폼 관리자 전용입니다.

## 로그 수집 → 보기 → Loki 전송

```
사용자 행동 ──auditLog()──────────► AuditEvent (audit 테이블)
앱 경고/오류 ──SystemLogRecorder──► LogEntry (source=system)
컨테이너 출력 ──ContainerLogCollector──► LogEntry (source=container)
                                     │
        /platform/logs 에서 보기·내보내기 │  ShipLogsToLokiJob (스케줄) ──► LokiClient ──► Loki ──► Grafana
```

| 역할 | 파일 |
|---|---|
| 켜기/끄기 (마스터 + 항목별) | `InstanceSettings` 의 `is_log_collection_enabled`, `is_audit_/system_/container_log_collection_enabled`, `is_loki_shipping_enabled` 와 `is…Active()` 메서드 |
| 시스템 로그 저장 | `app/Services/Logging/SystemLogRecorder.php` |
| 컨테이너 로그 수집 | `ContainerLogCollector.php`, `ContainerLogParser.php`, `app/Jobs/ContainerLogCollectionManagerJob.php`, `CollectContainerLogsJob.php` |
| Loki 로 보내기 | `LokiStreamBuilder.php`(형식), `LokiClient.php`(HTTP), `app/Jobs/ShipLogsToLokiJob.php` |
| 보관 기간 정리 | `LogEntry::pruneOlderThan()` (스케줄: `app/Console/Kernel.php`) |
| 화면 | `app/Livewire/Platform/Logs.php` |

사용자 행동을 기록하려면 한 줄: `auditLog('platform.sources.xxx', ['key' => 'value']);` — 비밀번호·토큰은 넣지 마세요.

## 소스(Git) 관리와 Forgejo

- 소스 추가는 **플랫폼 관리자만**, 사용은 모든 팀. 허용 목록(allow-list) 규칙은 `app/Services/Platform/SourcePolicy.php`.
- GitHub / GitLab 소스: `app/Livewire/Source/Github|Gitlab/Create.php`, 권한은 `app/Policies/GithubAppPolicy.php`, `GitlabAppPolicy.php`.
- Forgejo: 모델 `app/Models/ForgejoApp.php`, API 클라이언트 `app/Services/Forgejo/ForgejoClient.php`,
  저장소/브랜치 선택 화면 `app/Livewire/Project/New/ForgejoPrivateRepository.php`.
  배포 때의 clone 주소 만들기는 `app/Models/Application.php` 의 `forgejo…` 메서드. 토큰이 들어간 주소는 `remove_iip()` 로 로그에서 가립니다.
- Forgejo 토큰 권한: `read:user`, `read:repository` (이슈 봇은 `write:issue` 추가).
